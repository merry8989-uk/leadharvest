How it works

One click reads the page the way a person would

Most scrapers depend on one CSS selector, so they break the moment a site changes. LeadHarvest looks at four independent sources and keeps whichever one actually has data.

1

Tables

A page with a real table (Name / Phone / Email columns) becomes one record per row. Column headers are matched against a synonym list, so “Contact Person”, “Mobile No.” and “E-mail” all map correctly.

2

Repeated cards

Team pages, listings and directories are built from repeated blocks. The engine finds the smallest block that holds a contact signal, then reads each block as one person or business.

3

Single page

A contact page, profile or small business site becomes one record: the whole page is read together, and the address is split into city, state and pincode afterwards.

4

Structured data

If the site publishes JSON-LD or microdata (schema.org), every Person, Organization or LocalBusiness entity is read as its own record — the cleanest data a page can offer.

Inside every field, four fallbacks run in order: JSON-LD → microdata → tel:/mailto: links → your CSS selectors → regex → heuristics. Each value carries a confidence score, so a phone pulled from a structured telephone property outranks one guessed from raw text.

Data structure

You decide what a record looks like

The schema tab is where the extension stops being generic. Turn fields off that you never use, rename the ones you do, and teach it the ones it does not know.

Per field you can set

  • On / off — only enabled fields are scraped and exported
  • Label — the column header in Excel, PDF and CSV
  • Type — text, phone, email, URL, multiline or number
  • Required — flags records that are missing a must-have
  • Weight — how much the field counts towards confidence
  • Selectors — one CSS selector per line, tried in order
  • Regex — one pattern per line, capture group 1 is used
  • JSON-LD keys — comma separated property names

Presets, import and export

Four ready-made structures, one click each:

  • Phone book — name, phone, address, city, state, pincode
  • B2B leads — name, designation, company, email, phone, website, city
  • Directory / listing — company, phone, email, address, city, category, rating
  • Everything — all fifteen fields on

Export the whole schema as leadharvest-schema.json and import it on another machine, or keep it in version control next to your team's conventions.

AI advisor

“Which data is actually worth scraping here?”

The advisor looks at what the page offers — structured data, tel: links, tables, forms, address text, page type — and tells you which fields to enable, with a reason for each suggestion.

Local rules default

  • Runs entirely inside your browser
  • No API key, no account, no cost
  • Deterministic: same page, same advice
  • Explains itself in plain language
  • Works offline

Cloud AI optional

  • Bring your own key: Sarvam AI, OpenAI, Groq or any OpenAI-compatible endpoint
  • Only a short page summary is sent — never the full HTML
  • Off by default; nothing is sent until you enable it
  • Your key is stored locally and sent only to the provider you chose
If you leave cloud mode off, the extension never makes a single network request. That is the intended way to use it.

Local data

Your list lives on your machine

Records, history and logs are kept in the browser's extension storage. Nothing is uploaded, and there is no account to log into.

Records

Up to 5,000 records with all their fields, confidence scores and source URLs. Search, sort, edit, delete, export — all local.

History

The last 500 scrapes: when, from which page, which method was used, how many records, how long it took, which format you exported.

Logs

Scrape, export, settings and error events with levels and scopes. Emails and phone numbers are redacted before they are written.

Deleting is real. “Clear records”, “Clear history” and “Clear logs” wipe the data immediately, and uninstalling the extension removes everything with it. There is no copy anywhere else.
Install

Two minutes, either browser

Chrome, Edge, Brave, Opera

  1. Download and unzip the extension folder.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode.
  4. Click Load unpacked and pick the unzipped folder — the one containing manifest.json.
  5. Pin the LeadHarvest icon to the toolbar.

Firefox 140+

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on.
  3. Select manifest.json inside the unzipped folder.
  4. The add-on is active until you restart Firefox — permanent installs come from a signed build on addons.mozilla.org.
On a phone: Chrome for Android does not support extensions. Use a Chromium-based mobile browser that does (for example Kiwi Browser) with the Firefox build, or scrape on a desktop and send yourself the exported file — it is a few kilobytes and opens anywhere.
FAQ

Straight answers

Does it send my data anywhere?

No. Scraping, parsing, storage and file generation all happen inside your browser. The only network request the code can make is the optional cloud-AI advisor, which stays disabled unless you add your own API key and switch it on.

Why does it need access to all websites?

Because you point it at whatever page you are reading, and that could be any site. The extractor is not injected into pages automatically — the manifest declares no content scripts, and the code is injected only at the moment you click scrape. If you prefer, you can restrict the extension's site access in your browser's extension settings.

Is this legal to use?

Scraping publicly visible pages is widely done, but the rules depend on the site and the jurisdiction. Check the site's terms of service and robots.txt, collect only what you actually need, and remember that contact details are personal data — in India the DPDP Act 2023 gives people rights over it, including deletion. The extension is a tool; how you use it is your call.

What does it deliberately not do?

No crawling across many pages on its own, no logging into sites, no bypassing paywalls or captchas, no bulk email or WhatsApp sending, and no uploading to a cloud of ours. It reads one page you are looking at, when you ask it to.

Why did a page return zero records?

Usually one of three things: the page loads its content on scroll (turn on “auto-scroll before scraping”, or scroll manually first), the contact details are inside an image, or the site hides them behind a form. Opening the individual detail or contact page and scraping that usually works.

Excel shows the phone number as a number and drops the plus sign.

Phone numbers and pincodes are exported as text on purpose, so leading zeros survive. If your spreadsheet app still reformats them, set that column to “Text” before importing.

Hindi or Tamil text turns into question marks in the PDF.

The built-in PDF writer uses the standard PDF fonts, which only cover Latin script. For Indic scripts, export as HTML and print to PDF from the browser, or use the “Print / PDF” button — the browser has the right fonts.

Can I use it for my team?

Yes, but there is no sync: each browser keeps its own local list. Share the exported Excel file, or share a schema JSON so everyone collects the same fields.
