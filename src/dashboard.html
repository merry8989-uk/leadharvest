Kaise use karein

  1. Install: chrome://extensions → Developer mode ON → "Load unpacked" → is folder ko select karein.
  2. Scrape: koi bhi website kholein (contact page, team page, directory listing), toolbar par LeadHarvest icon dabayein → "Is page se contact data scrape karein".
  3. Check: Dashboard → Data tab me sab records dikhte hain. Cell par click karke edit bhi kar sakte hain.
  4. Export: format chunein (Excel / CSV / PDF / TXT / Notes / JSON) → Export. File Downloads folder me chali jaati hai — wahan se phone/Drive par bhej dein.
  5. Structure badlein: Data structure tab me fields on/off, rename, custom selector/regex, custom field add karein.

Data kaise nikalta hai (order)

  1. Table rows — agar page par header wali table hai (Name / Phone / Email columns), har row ek record.
  2. Repeated cards — team/listing pages par har card ek record.
  3. Single page — contact page ya business site par pura page ek record.
  4. Har field ke andar priority: JSON-LD → microdata → tel:/mailto: links → CSS selectors → regex → heuristics.
